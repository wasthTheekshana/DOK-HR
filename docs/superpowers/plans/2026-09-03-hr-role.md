# HR Role Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a new `hr` role that can view Sites, Team, and Attendance — company-wide, read-only — and nothing else.

**Architecture:** Follows the same pattern used for `project_manager`: add `'hr'` to the DB role check constraint, the Zod validation schemas, and the relevant `requireRole` arrays / frontend route guards. No new tables, no new backend query logic — `GET /sites`, `GET /sites/:id`, `GET /attendance`, and `GET /attendance/report` already have no role restriction, and the controllers behind them only special-case `supervisor`/`staff` filtering, so every other role (including `hr`) already gets unfiltered, company-wide data. Read-only is achieved by never adding `'hr'` to any mutation route's `requireRole` list or any frontend write-control role check.

**Tech Stack:** PostgreSQL, Express + TypeScript (Jest + Supertest for backend tests), React 18 + TypeScript + Tailwind CSS, Lucide React icons. The client has no test framework configured — frontend tasks are verified with `npx tsc --noEmit` plus a manual smoke test, matching how prior frontend-only work in this repo was verified.

**Spec:** `docs/superpowers/specs/2026-09-03-hr-role-design.md`

## Global Constraints

- No changes to existing tables' columns or existing rows — the only schema change is widening `users.role`'s check constraint (additive).
- `'hr'` must never be added to any mutation route's `requireRole([...])` array (sites POST/PUT/PATCH/DELETE, users POST/PATCH/DELETE, attendance POST) or any frontend button/column visibility check that currently excludes non-admin roles.
- `'hr'` must never be added to nav items or routes for: Dashboard (redirected instead), Daily Tasks, Task Summary, Payroll, Extra Units, Invoices, Invoice Analysis, Reports, Analytics, Target Performance, Time Site Analysis, Service Analysis, Project Planning, Staff KPI.
